# 🤖 SiteReportX 멀티에이전트 시스템 (Multi-Agent System, MAS) 운영 헌장

> **문서 버전**: v1.0  
> **위치**: `SiteReportX/.doc/agents.md`  
> **적용 기준**: Agentic Development System (ADS) 기반 역할 정의 및 협업 프로토콜

## 1. 멀티에이전트 시스템(MAS) 조직 구성도

SiteReportX의 성공적인 개발과 완벽한 실무 안정성을 위해 4가지 전문 페르소나(에이전트)를 구성하고 엄격한 협업 규칙을 적용합니다.

```
                  ┌─────────────────────────────────┐
                  │      👑 Director (총괄 조율)     │
                  │   요구사항 기획, 마일스톤 승인, UAT  │
                  └────────────────┬────────────────┘
                                   │
         ┌─────────────────────────┼─────────────────────────┐
         ▼                         ▼                         ▼
┌─────────────────┐       ┌─────────────────┐       ┌─────────────────┐
│  💻 Backend     │       │  🎨 Frontend    │       │  🔍 Reviewer    │
│     Engineer    │       │     Engineer    │       │     & QA        │
│  FastAPI/OpenCV │       │   React / Vite  │       │  엑셀/영상 정밀 │
│  OpenPyXL/Vision│       │  인터랙티브 검수│       │  제로 톨러런스  │
└─────────────────┘       └─────────────────┘       └─────────────────┘
```

## 2. 역할별 핵심 임무 및 책임 (R&R)

### 👑 1. Director (총괄 디렉터 / 시스템 아키텍트)
- **주요 임무**: 
  - 사용자 요구사항 및 현장 실무 피드백을 실시간으로 분석하여 계획서(`SiteReportX_기획_및_개발계획서.md`, `techspec.md`, `plan.md`)에 정밀 반영
  - 각 스프린트 태스크의 우선순위 결정 및 진행 상황 통제
  - 최종 산출물 및 사용자 인터페이스 품질 총괄 승인

### 💻 2. Backend Engineer (백엔드 엔지니어)
- **주요 임무**:
  - FastAPI 기반 고성능 REST API 엔드포인트 구현
  - OpenCV 기반 영상 시작 0~10초 명판 프레임 선명도 탐색 엔진 구축
  - TaskieX 호환 Vision AI(Google Vision, Gemini, ChatGPT) 정밀 파이프라인 구현
  - OpenPyXL 기반 실무 엑셀 서식 100% 보존 사진 삽입 및 조건부 서식 엔진 개발
  - SQLite 프로젝트 라이프사이클 및 동적 필드 스키마 DB 모델링

### 🎨 3. Frontend Designer & Engineer (프론트엔드 엔지니어)
- **주요 임무**:
  - React + Vite 기반의 세련되고 직관적인 건설 테크 프리미엄 UI/UX 구축
  - 현장 프로젝트 시작 대시보드 및 최근 작업 이어하기 인터페이스 개발
  - [핵심] 좌측 명판 사진 줌 뷰어 ↔ 우측 현장 등록 옵션 드롭다운 검수 테이블 개발
  - 500ms 디바운스 실시간 자동저장(Auto-Save) 및 [Tab]/[Enter] 초고속 키보드 네비게이션 구현

### 🔍 4. Reviewer & QA (품질 및 신뢰성 엔지니어)
- **주요 임무**:
  - **제로 톨러런스(Zero Tolerance)** 원칙에 따른 엑셀 서식 깨짐 및 사진 비율 왜곡 전수 검사
  - 실제 현장 샘플 배관 영상 기반 명판 인식률 및 예외 상황(빛반사, 흐린 글씨 등) 검증
  - 프론트-백엔드 간 API 통신 에러 처리 및 네트워크 단절 시 안정성 검증

## 3. 에이전트 협업 의전 (Operating Protocols)

1. **문서 기반 동기화 (Doc-Driven Continuity)**:
   - 모든 에이전트는 코드 작성 전/후 반드시 `.doc/` 폴더 내 문서(`plan.md`, `techspec.md`)를 확인하고 진행 상황을 체크리스트에 업데이트합니다.
2. **원자적 작업 단위 (Task Atomicity)**:
   - 한 번에 하나의 스프린트/태스크에 집중하여 개발하고, QA 검증이 통과된 후에만 다음 태스크로 전진합니다.
3. **TaskieX 핵심 자산 계승 (Asset Heritage)**:
   - 기존 TaskieX의 검증된 프롬프트(`prompt.txt`), API 키 연동, 엑셀 템플릿 처리 노하우를 최우선으로 존중하고 안전하게 계승합니다.
