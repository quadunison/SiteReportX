# 📋 TaskieX 스타일 직관적 모드 개편, 실시간 로그 콘솔, 마스터 템플릿 업로드 및 웹 미리보기 구현 계획서

> **작성 일시**: 2026-08-25  
> **프로젝트**: SiteReportX (건설 현장 배관내시경 검사 보고서 자동화 웹 플랫폼)

---

## 1. 개요 및 목적
1. **TaskieX 스타일 직관적 3대 모드 탭 구조**:
   - 모드 1: `[AI 명판 인식 & 검수 에디터]` (파일명 표준화 및 검수)
   - 모드 2: `[웹 실시간 엑셀 보고서 미리보기]` (시트별 리포트 뷰어)
   - 모드 3: `[실시간 작업 로그 & 통계]` (작업 피드백 터미널)
2. **최초 마스터 템플릿(.xlsx) 전용 업로드 관리**:
   - 현장별 기준 엑셀 마스터 템플릿을 손쉽게 교체/업로드/다운로드
3. **웹 실시간 엑셀 보고서 미리보기**:
   - 엑셀을 열지 않고도 웹 화면에서 4대 배관 시트의 완성된 보고서 형태를 즉시 검토
4. **실시간 로그 피드백 시스템**:
   - 분석, 페어링, 정규화 단계별 실시간 콘솔 피드백 제공

---

## 2. 세부 구현 계획
- 백엔드: 로그 버퍼, 템플릿 업로드 엔드포인트 추가
- 프론트엔드: `ReportPreview.jsx`, `ProcessLogViewer.jsx`, `TemplateUploadModal.jsx` 컴포넌트 추가 및 `InspectionWorkspace.jsx` 탭 통합
- 프로덕션 빌드: `npm run build`
